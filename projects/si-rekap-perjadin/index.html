Pengaturan Aplikasi

Konfigurasi tampilan
-
-
-
DB_REKAP_PERJADIN, DB_PESERTA, MASTER_PEGAWAI

Filter periode diterapkan dari sidebar kiri. Versi asli membaca Google Spreadsheet secara langsung; demo ini memakai data simulasi di browser. Untuk memperbarui tampilan setelah mengubah data di sheet, klik Terapkan Filter.

1. Filter Data

Gunakan panel Filter Periode di sidebar: pilih Tahun, Bulan Biro, dan Jenis Perjadin, lalu klik Terapkan Filter. Semua halaman menggunakan filter yang sama.

2. Membaca KPI

  • Total Perjadin — jumlah register sesuai filter.
  • Berkas Lengkap — data dengan status Lengkap.
  • Proses Verifikasi — sedang diverifikasi.
  • Belum Lengkap — masih perlu dilengkapi.

3. Melihat Data Detail

Menu Data Perjadin menampilkan seluruh register dengan pencarian dan filter tambahan. Gunakan pagination di bawah tabel untuk navigasi halaman.

4. Cetak Laporan

Buka menu Laporan, periksa rekap, lalu klik Cetak Laporan atau gunakan Ctrl+P. Hanya konten laporan yang akan dicetak.
