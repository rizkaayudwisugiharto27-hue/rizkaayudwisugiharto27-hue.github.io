# Portofolio Rizka Ayu Dwi Sugiharto

Website portofolio pribadi, di-host dengan GitHub Pages.

Alamat: https://rizkaayudwisugiharto27-hue.github.io

## Cara update
Seluruh website ada di satu file: `index.html` (gambar sudah tertanam di dalamnya).
Untuk mengubah teks (pengalaman, keahlian, kontak), buka `index.html` di GitHub,
klik ikon pensil (Edit), ubah teksnya, lalu klik **Commit changes**.
Perubahan tampil di website dalam 1–2 menit.
